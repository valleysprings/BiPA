# selection_replay

Replays of the optimizers' own selection rules on copies of the seed. `python -m aux.selection_replay.selection compute` writes `selection.json`, `dev2test.json` and `mech_selection.md` (the dev gain each rule reports when no candidate differs from the seed, DeepSeek Table 1 runs); `draw` draws `mech_dev2test4.{pdf,svg}` and reads `table1.json` from `python -m src.analysis table1`.
The task model is fitted to the seed's distinct dev and test executions (`selection.seed_executions`, checked against `PAPER_INPUTS`: dev tasks / dev executions / test executions 9/18/54 for TB2, 30/90/225 for tau3, 30/89/360 for AutoBench). One dev evaluation of tau3 and one of AutoBench come from runs the assets no longer hold; their outcomes and input tokens are kept in `aux/data/seed_dev_extra.json` with the runs they came from, and are added only when none of those runs is found.
The other scripts import its task model: `luna` (the GPT-6-Luna replay, `mech_selection_luna.md`), `devsize` (the dev-set-size sweep, `mech_devsize.md`), `selection_fig` (the `mech_selection` figure from `selection.json`), `fig_priorfit` (`mech_priorfit.{pdf,svg}`: the share of tasks the seed solves in no run, some runs or all runs, dev and test, against the fitted prior), and `collect`, then `fig_devpertask` (task-by-task dev and test flips, the `mech_devpertask` figure).
Run from the repo root, e.g. `python -m aux.selection_replay.luna`, `python -m aux.selection_replay.devsize`. Outputs go to `$BIPA_OUT/selection_replay/`, records and figures to `$BIPA_OUT/{data,fig}/mech/`, caches to `$BIPA_ASSETS/cache/analysis/main/`.
