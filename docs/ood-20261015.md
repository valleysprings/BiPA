# OOD 实验（leave-one-domain-out）— 2026-10-15

目标 claim（用户指定）：in-domain 的成功率差是噪声，OOD 上严格变差。对应 PENDING.md P1-4(a)：同一 benchmark 内留出 domain，在部分 domain 上优化、在其余 domain 上测。本文档记录调查结论、设计、启动与预算。

## 调查结论（决定设计的三条事实）

1. **dev/sel 覆盖全部 domain，严格的留出 domain 无法复用现有 skill。** τ³ 的 D_sel（30 题）含全部 4 个 domain（airline 4 / banking_knowledge 8 / retail 9 / telecom 9），train（155–160 题）同样含 banking_knowledge 36 题；AutoBench 的 sel/train 覆盖全部 6 个 domain。因此 9 个 learned skill（native-20261008-https）在优化和选择阶段都见过每个 domain，"留出 domain 上测现有 skill" 在测量上不成立，必须新跑一个从未见过留出 domain 的优化 run。
2. **跨 benchmark 的 OOD 已有 rep0 产物，但不能支撑该 claim。** `execution/deepseek-flash/<method>/<bench>/ood-from-bench-*/`（transfer_bench.py，单次 run）显示 τ³ 学到的 skill 迁到 AutoBench 与 seed 基本持平（Q 44.2–45.0，in-domain seed 参考 45.0），不是"严格变差"；跨任务族太远，阴性或持平结果都没有诊断价值。registry 里另有 deepswe/cybergym/secbench-pro/patcheval，同属跨任务族，同样不具备 domain-holdout 的解释力。
3. **DeepSeek-flash 的优化 run 成本远低于先前的担心，LODO 重训在预算内。** 主 run 实际执行的 rollout token（assets/cache/analysis/mech/optcost.json，executed 口径）：SkillOpt τ³ 217M 输入 / 0.2M+2.4M 输出；GEPA τ³ 390M 输入。仓库与产物里没有美元计费记录（episode 的 cost_usd 为 null），按 flash 档公开价上限估：输入 $0.30/1M（全部未命中缓存的最坏口径）、输出 $1.20/1M；若网关有 prompt 缓存（mech_price3 的主权重 c=0.1），实际约为最坏口径的 1/5–1/4。

## 设计：τ³ leave-one-domain-out（LODO），留出 banking_knowledge

留出 banking_knowledge 的理由：它是 τ-Knowledge（arXiv 2603.04370）并入 τ³ 的知识库问答任务族，与 airline/retail/telecom 的工具使用任务分布差异最大；in-domain 它也是最难的 domain（seed avg@3 仅 35.1%，工具 domain 84–99%，mech_domains.json）。test 面板 19 题。

- 新 scale `lodo-banking`（baselines/bipa/configs/tasks.yaml）：train 与 dev 在抽样**之前**丢弃 `^tau3-banking_knowledge-`（panels.py 新增 `drop_tasks`），D_sel 随之不含 banking（27 题 = 全部非 banking dev）；test 面板与 main 完全相同（75 题，含 19 题 banking）。train_episodes=160、batch 结构、cap 与 main 一致——唯一的操纵是 domain 组成。
- 两个 cell：SkillOpt 与 GEPA × tau3-bench，tag `native-20261015-lodo-banking`，各自 test×3（avg@3，rep0 由 run.py、rep1/2 由 repeat.py 补入 test-reps，与主战役同一协议）。
- 对照全部免费：seed 与 no-skill 在这 75 题上的三次评测是 Table 1 的既有缓存（同一 version、同一 cache root，按 task×rep 命中）。分析按 domain 配对：held-out 19 题（OOD）与其余 56 题（in-domain 对照，验证 LODO skill 在训练分布内表现正常）。
- 能支撑的 claim：在同一优化器、同一预算下，仅移除一个任务族的训练/选择暴露，测得的 held-out 族 Q 差（skill−seed，avg@3，配对）与 in-domain 56 题 Q 差的对比；以及两侧的 token 比 ρ。若 held-out 上 Q 严格低于 seed 而 in-domain 持平，即"in-domain 差是噪声、OOD 严格变差"的直接证据。
- 不能支撑的：优化器 run 间方差（每个 cell 只有一个 LODO run）；AutoBench 的 domain holdout（未跑，见"未做"）；19 题上的中小效应（n=19 的 Q 差 MDE 约 ±15pp，小效应检不出；ρ 的配对检验在 n=19 下功效足够，参照 TB2 n=18）。
